# ③ 파이프라인 단계별 진단 — 완료

**요구**: 모듈별(GroundingDINO · SAM 2.1 · UniDepthV2 · Back-projection) 실행 결과를
샘플로 확인해 잘하는 것과 못하는 것을 정리.

**피드백 반영**: 처음에는 모듈마다 서로 다른 에피소드의 예시를 붙였다. 그러면 3D 박스가
틀렸을 때 검출·분할·깊이 중 무엇이 원인인지 가릴 수 없다는 지적을 받아, **한 프레임에서
다섯 단계를 모두 뽑아 한 장에 담는 방식**으로 다시 만들었다.

## 1. 단계별 스트립 (주력)

[`단계별_스트립/`](단계별_스트립/) — 한 (에피소드 · 카메라 · 프레임)에서 나온 6개 패널을
2행 3열로 배치하고, 단계마다 정상 / 주의 / 이상 / 미진입 판정과 근거를 달았다.

```
원본 프레임 │ ① GroundingDINO 2D 박스 │ ② SAM 2.1 픽셀 마스크
③ Depth     │ ④ 역투영 점군(위에서)     │ ⑤ 3D 박스
```

①과 ⑤ 패널은 파이프라인이 실제로 낸 산출 영상(`BOX2D.mp4`, `A_visible.mp4`)에서 그대로
뽑았고, ②③④는 같은 프레임에 같은 입력으로 다시 계산했다. 보고용으로 따로 그린 그림이 아니다.

④ 패널의 주황 사각형은 **파이프라인이 최종 채택한 3D 박스의 발자국**(중심·크기 그대로)이고
초록 점은 필터 전 원본 점군이다. 둘을 같은 축에 겹쳐야 "점군은 이런데 박스는 이렇게 잡혔다"가 보인다.

| 파일 | 대상 / 카메라 | 처음 어긋난 단계 | 최종 3D 박스 |
|---|---|---|---|
| `traj_T1_oreo_head` | 오레오 / 머리 | 없음 (기준선) | 9.3×5.7×2.3cm — 실물과 일치 |
| `traj_T2_laptop_he` | 노트북 / HE 1인칭 | 없음 (기준선) | 46.6×22.8×23.9cm — 타당 |
| `traj_T3_charger_head` | 충전기 / 머리 | **① 검출** | 산출 안 됨 (결과 누락) |
| `traj_T4_duster_he` | 먼지떨이 / HE 1인칭 | **② 분할** | 33.2×14.2×10.8cm — 뒤 단계가 흡수 |
| `traj_T5_cube_wrist` | 루빅스 큐브 / 손목 | **③ 깊이** | 11.7×16.8×7.3cm — 실물의 약 3배 |
| `traj_T6_apple_head` | 사과 / 머리 | **④ 역투영** | 6.4×5.4×1.4cm — 두께만 1/5 |

읽는 요령 두 가지:

- **T6이 "3D 박스만 잘못된" 경우다.** 검출·분할·깊이가 전부 정상인데 최종 크기의 깊이 축만
  무너진다. 단일 시점이라 물체 뒷면 점이 원리적으로 존재하지 않기 때문이다.
- **T4는 그 반대다.** 분할이 229조각으로 깨졌는데도 뒤 단계 필터가 걸러내 최종 크기는
  실물에 근접했다. 단계별로 나눠 보지 않으면 T6과 T4를 구분할 수 없다.

[`단계별_스트립/원본패널/`](단계별_스트립/원본패널/)에 합성 전 패널 원본과 점군(`.npy`),
수치(`meta.json`)가 있다.

## 2. 모듈별 개별 사례 (보조)

[`모듈별_개별사례/`](모듈별_개별사례/) — `<데이터셋>/<모듈>/{베스트, 워스트}/` 구조.
모듈 단위로 강·약점을 훑을 때 쓴다. 파일명이 곧 사례 요지다.

후보 약 100장을 전량 렌더한 뒤 전량 육안 검증해 라벨에 부합하는 것만 채택했고,
수치상 워스트지만 눈으로 멀쩡한 후보 9건은 제외했다. 판정 근거 전체는
[육안검증_판정기록.json](육안검증_판정기록.json), 선정 기준과 사례 수가 적은 사유는
[샘플선정기준.txt](샘플선정기준.txt)에 있다.

## 3. 모듈별 요약

| 모듈 | 잘 되는 조건 | 무너지는 조건 |
|---|---|---|
| GroundingDINO | 머리 카메라의 중형 물체 — PickDoll 100%, 큐브 99% | 흰 로봇 팔과 색이 겹치는 소형 물체 — 충전기 실검출 22~32% |
| SAM 2.1 | 물체가 온전히 보이면 윤곽을 픽셀 단위로 추종 | 로봇 팔이 물체를 가로지르면 조각남 — 먼지떨이 229조각 |
| UniDepthV2 | 중거리 1~3m에서 상대오차 21.7% | 근접 0.3~0.8m에서 43%, 프레임 간 ±8~10% 흔들림 |
| Back-projection | 물체가 깊이 방향으로 누워 있으면 부피가 나옴 | 구형·소형은 앞면 껍질만 잡혀 두께가 무너짐 |

WildCamera는 쓰지 않는다. UniDepthV2가 내부 파라미터를 함께 출력해 필요가 없어졌고,
코드 호출이 0건임을 확인했다.
